# 排错

## 找不到显示器

运行 `./mic.sh devices`，确认线材支持 USB 数据、端口模式允许数据/调试，并在显示器上授权。`unauthorized` 表示未授权；只有画面或充电不足以证明 USB 连通。当前只接受 ADB 型号 `MiTV_MFFU1`，候选机型条件见[兼容性](compatibility.md#机型)。

若过夜后 ADB 开关被关闭，需要在显示器重新打开；可选安装 [USB ADB 开关守护](guardian.md)避免这一类断连。守护不修复物理断线或未授权连接。

## BlackHole 存在但没有声音

1. 运行 `./mic.sh status` 和 `./mic.sh doctor`。
2. 查看 `~/Library/Logs/Mi Monitor Mic/service.log` 末尾错误。
3. 确认目标应用选择 BlackHole 2ch、未静音且有麦克风权限。
4. 实际说话验证；后台已加载和设备存在都不等于应用已收到人声。

断流或输出堵塞时，服务会结束此次采音，约 20 秒后重试。

## 声音太小或失真

先 `./uninstall.sh`，再用 `./install.sh --gain 5` 调整默认倍数 `1`。增益也会放大噪声，过高会削顶失真，应逐步调整。

## 微信菜单没有 BlackHole

本工具不控制微信设备列表，系统默认输入也不足以证明通话使用了它。可尝试完全退出并重开微信，再结合通话中音量与对方反馈定位。当前[尚未验证通过](compatibility.md#待设备验收)。

## 升级后提示依赖路径不存在

ADB 被移动或删除时，用 `./install.sh --adb /新的路径/adb` 修复；沿用原设备绑定和增益。若只需卸载，运行 `./uninstall.sh --adb /新的路径/adb`，仍须连接并授权原 USB 设备。

scrcpy、server 或 Python 路径变化时，卸载后用当前依赖重新安装；第三方依赖会保留。非标准路径可通过[安装参数](../README.md#可选分别安装)指定，scrcpy 与 server 须版本匹配。

## 卸载提示归属不符

检查提示的文件，不要通过删除无关目录绕过保护。正常卸载只移除本项目应用、运行目录与登录任务；日志保留，可按需手动删除。
